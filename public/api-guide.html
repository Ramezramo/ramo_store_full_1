Authentication

1

Native PHP — Device Token (AES-256)

POST your device ID to /ntv-php/ntv-register-device.php. You get back an encrypted token. Send it as Authorization: Bearer <token> on protected native routes (e.g. tags).

2

Laravel API — Laravel Sanctum Token

Login via POST /api/user/login (customer) or POST /api/vendor/login (vendor). You receive a cookie token. Send it as Authorization: Bearer <cookie> on all protected Laravel routes.

3

Vendor-only routes need the vendor middleware

Some routes require both a valid token AND that the authenticated user has a vendor role. Logging in as a regular customer will return 403.
